# 前端卡尔曼滤波实验设计

第一次审阅建议先读 [实验审阅说明](EXPERIMENT_REVIEW_BRIEF.md)，它把数据、算法实际计算、结果与未验证假设串在一起。本文集中说明控制变量与评价设计，不要求读者运行程序。

## 研究问题

本阶段调试滤波实现与不确定性传播，依次回答：GICP 能否产生可靠的位姿和协方差？同一观测下 ESKF 是否按 P/R 正确计算更新？独立点级 ESIKF 的迭代与后验是否合理？数值正确之后，真实误差是否改善？

静态场景指场景中的物体静止，相机仍有机械臂带来的平移和转动。为隔离滤波问题，实验不运行动态点滤除、RAFT、后端与后验反馈。

## 数据、先验和帧对

六条 FR5 + ZED X 录制分别包含上移、前移、右移、偏航、俯仰和滚转。每条跳过前 60 帧曝光过渡段，用至少 200 个静止 IMU 样本初始化，随后连续纯惯性传播，冻结所选时刻的状态均值和完整 21×21 P。各算法的后验不传播到其他案例。

| 案例 | 原始 source_frame_id | 作用 |
|---|---|---|
| static_start | 110 → 111 | 开始静止段 |
| sync_motion | 185 → 186 | 同步摆动段 |
| main_motion | 340 → 341 | 主运动相邻帧 |
| main_motion_long | 340 → 346 | 主运动较长间隔 |
| static_end | 640 → 641 | 结束静止段及长时间 P 传播 |

帧对、P/R 对照值预先固定；没有根据 GT 搜索最优默认值。数据坐标系、时间补偿、标定及已知采集问题见 [FR5_DATASET.md](FR5_DATASET.md)。GT 只由报告程序读取。

## 模块实验

| 实验 | 输入 | 处理 | 主要检查 |
|---|---|---|---|
| GICP | 同一点云、IMU 初始相对位姿 | 欧氏 GICP 与投影 Stereo-GICP 独立配准 | 误差、对应点、迭代、Hessian、R、收敛状态 |
| ESKF | 冻结的先验均值、完整 P、同一位姿观测和完整 R | 比较 0.1R / R / 10R 与固定对角 R | 实际 K、创新、S、NIS、状态修正和后验 P |
| ESIKF | 同一点云与 IMU 先验 | 独立点级更新；几何权重 1.0 与 0.5 | 逐轮对应点、信息矩阵、虚拟 R、K、修正和 P |

GICP 的左右扰动约定通过共享雅可比转换到 ESKF 的 `[δθ_body, δp_world]`，保留旋转和平移交叉项。ESIKF 不读取 GICP 位姿、GICP 的 R 或 ESKF 后验。固定 R 默认旋转标准差 0.5°、位置标准差 0.02 m。

配准版本固定为 `robotic-front/744ac2d993ae629b0cc44a3b1d995e04ab4fad48`，默认 20 轮、最少 20 个对应点；具体参数在 [baseline.yaml](../experiments/fusion/configs/baseline.yaml)。Stereo 上游在迭代耗尽时可能仍返回 `converged=true`，所以同时保存 `solver_status`。`valid` 只代表输入/数值有效。

## 协方差修复对照

模型视差、帧对、配准和观测参数固定。每条序列执行：

| 组别 | 改变的变量 | 保持的变量 | 六条合计 |
|---|---|---|---:|
| reference | 旧实现记录 | 历史记录原样保存 | 360 |
| solver_only | ESKF 改为无量纲归一化求解 | 旧观测、均值、完整 P | 240 |
| repropagated | 修正初始 P 的轴索引并重新传播 | 图像、视差、均值、GICP 参数；配准结果经核对一致 | 360 |
| sensitivity | 预先固定 P×0.0001，比较 0.1/1/10/1000/100000R 与固定 R | 新观测与均值 | 360 |

新增三组总计 **960 条**。solver_only 与 sensitivity 每条 GICP 观测产生多个 ESKF 更新；不是 960 个独立样本，也不应与数据量或显著性等同。

## 指标与判断边界

平移误差使用米制欧氏距离，旋转误差使用 SO(3) 对数向量的模长。报告把 GT 相对运动转换到机体系，并使用共同的估计锚点计算条件帧对误差；分组取 RMSE，保留失败数量。

数值检查包括输入观测有限、R 正定、后验 P 有限且在容差内对称半正定，以及 K 与独立 NumPy 求解的对照。精度检查分别比较先验、GICP 观测和滤波输出；不因更新有效而判定精度改善。

这些结果不是完整前端闭环轨迹 ATE。P 来自长期绝对惯性传播，锚点与当前状态的相关性尚未进入观测模型；Hessian R 是近似值，噪声也尚未标定。少量相关帧对下的小 NIS 不能单独证明统计一致性。详细数值见 [协方差诊断](FUSION_COVARIANCE_DIAGNOSIS.md)。
