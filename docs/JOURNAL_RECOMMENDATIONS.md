# SIO_SLAM 期刊投稿推荐

本文档汇总 SCI 论文规划中的候选期刊指标，便于开题、基金与投稿决策。指标来源见文末「数据来源与更新说明」。

相关论文框架见 [SCI_五篇论文索引.md](SCI_五篇论文索引.md)。

## 指标说明


| 指标          | 含义                                                                                   |
| ----------- | ------------------------------------------------------------------------------------ |
| **IF（JIF）** | Clarivate Journal Impact Factor；统计年前两年论文在统计年被引次数 ÷ 前两年可引论文数                          |
| **JCI**     | Journal Citation Indicator，学科归一化引文影响力；**JCI = 1.0** 为同学科平均水平，**> 1** 高于平均            |
| **JCR Q**   | Web of Science 按 IF 四分位；机器人学科以 **ROBOTICS** 为准（一刊多学科时表中取主相关类）                        |
| **审稿周期**    | 单元格拆成 **首决** 与 **见稿**。首决是投稿到第一次决定；中位若**含编辑拒稿/初筛**，不是外审耗时。见稿沿用出版方自己的口径（投稿到接收、接收到在线，或投稿到 ePublication），三者不混用 |


## 候选期刊总表

数据基准：

- **IF / JCI / JCR Q**：Clarivate **JCR 2025 年指标**（**2026 年 6 月**发布）
- **审稿周期**：优先出版方期刊页的首决与见稿；官网没有新数字时保留旧估计并标经验值。LetPub / 科研通只作二次来源（个体差异大）

SLAM适合度与收录领域分开，只表示这两类稿（动态观测滤波、立体配准、以及后两篇的后端/系统）是否该投此刊。三个取值只有适合、贴边、不适合。

- **适合**：SLAM、视觉惯性里程计、动态物体剔除、点云配准是该刊常规稿。
- **贴边**：可以收，但必须改写成该刊的主业（测量不确定度、移动测图、传感器数据、渲染），整篇写成 SLAM 系统容易范围不符。
- **不适合**：主业不是这个方向，这两篇不要投。

Autonomous Robots 标适合，同时要有真实机器人上的表现。IJCV、CVIU 标适合，按视觉方法收感知模块，SLAM 系统长文不是主业。TVCG、The Visual Computer 标贴边，只对应 3DGS / 渲染那一篇。各篇对照表按该篇重标，不照搬本表。

> **相对上一版文档的主要勘误**  
>
> 1. 数据基准已从「2024 JCR（2025 年 6 月发布）」更新为「**2025 JCR（2026 年 6 月发布）**」。
> 2. **IJRR** 最新 IF 为 **7.7**（旧表 5.0 对应上一统计年；勿与 Scopus Impact Score ≈ 7.5 混用）。
> 3. **RA-L** 按 IF 在 ROBOTICS 现为 **JCR Q2**，但 **JCI 仍为 Q1**（约 8/48）——社区认可度不能只看 JIF 四分位。
> 4. **Autonomous Robots** IF 升至 **6.0**。

## 按论文规划对照

基线对比：**ORB-SLAM3** 发表于 **T-RO**（现 IF 11.1）；早期视觉 SLAM 系统工作亦常见于 **IJRR**。其他对标：**VINS-Fusion**、**DynaSLAM**、**Gaussian-SLAM / SplaTAM / Photo-SLAM**。

各篇表中的 **SLAM适合度** 按这一篇计。总表是期刊通论。

### 1. 动态观测滤波

对应框架：[SCI_动态观测滤波.md](SCI_动态观测滤波.md)

## 如何用 JCI / JCR Q / 审稿周期辅助选刊

- **JIF Q2 但 JCI Q1**（如 **RA-L**）：按 IF 四分位看似下降，学科归一化影响力仍强。作者页承诺首决 ≤3 月、终决 ≤5 月；录用后 Rapid Posting，或自投稿起 6 个月内在 Xplore 上线，否则拒稿。适合赶毕业/会议展示窗口。
- **首决中位极短要看是否含编辑拒稿**（如 Autonomous Robots）：2026-10-25 官网首决中位为 3 天，含编辑拒稿，外审见稿无官方中位，不能把这 3 天当成审稿时间。
- **IF 与 JCI 均强**（如 T-RO、TVCG）：适合冲刺。T-RO 进入外审后的首决目标约 3 月（AE 指南）；见稿无官网中位，整轮常需预留 1 年量级（经验值）。
- **对比 ORB-SLAM3**：原文在 **T-RO**；系统长文亦可对标 **IJRR**（更慢，周期仍是经验值）。测量叙事的模块首投 **Measurement**；机器人社区的 letter 是 **RA-L**（JCR **Q2**）。

## 结合当前实验阶段的建议

动态滤波与 Stereo-GICP 已够按测量叙事投稿，不必等整系统 ATE。

1. **动态观测滤波、Stereo-GICP 首投**：**Measurement**（Q1；首决含初筛 7 天，外审后决定 57 天，投稿到接收 126 天）。SLAM适合度是贴边，写成位姿协方差一致性或测量算法性能。
2. **机器人社区备选**：**IEEE RA-L**（JCR ROBOTICS **Q2**，IF 5.3；首决承诺 ≤3 月）。SLAM适合度是适合。两篇若都投，分成两封 letter。
3. **Stereo-GICP 测图备选**：**Geo-spatial Information Science**（贴边；改写成移动测图配准；外审后首次决定平均 62 天）。
4. **ESIKF**：不投 IEEE TIM。不确定度一致性可投 Measurement（贴边）；机器人 letter 为 RA-L（Q2）。本模块单独不支撑 T-RO。
5. **系统收官**：完整系统胜过强基线后再投 **T-RO** 或 **IJRR**（周期为经验值）。**RAS** 是 Q1 长文，投稿到接收 244 天，不是快选择。3DGS 在渲染与位姿都强时冲 **IJCV** 或 **TVCG**；实用 letter 仍是 RA-L（Q2）。
